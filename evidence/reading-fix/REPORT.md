# 公式与长目录修复 — 2026-11-11

## 问题及修复

1. **公式一直按普通 Markdown 输出。** 补充 remark-math 6.0.0、rehype-katex 7.0.1 与匹配的 KaTeX 0.16.47；依赖通过 package.json / lockfile 固定。`$…$` 行内公式和 `$$` 独立公式在构建期生成 HTML 与可访问的 MathML；样式、字体由站点本地提供。浏览器不运行公式解析脚本，不依赖 CDN。
2. **长公式不能撑宽正文。** 独立公式保留居中，小于正文宽度时不出现额外横向空间；更长的公式在自身区域滚动，并可通过键盘聚焦。KaTeX 内容保留固有宽度，避免居中溢出时开头被裁掉。
3. **长目录占满短窗口。** 目录标题与条目拆开；标题保持可见，条目容器独立滚动并限制滚动传递。高度上限同时预留初始文章顶部间距、导航和下方安全空间，修复只有滚动后才满足高度预算的问题。
4. **目录离正文太近。** 桌面正文仍为 700px，目录仍为 200px；间距从 72px 增至 120px。阅读容器从 972px 扩至 1020px，不修改首页或其他页面布局。
5. **当前目录项可能滚出可见范围。** 仅在当前章节切换时，将对应条目移入目录可视范围；直接调整目录容器的 scrollTop，不调用会影响页面的 scrollIntoView，不改 URL、不抢焦点。用户手动浏览目录时不会被持续拉回。
6. **点击章节后高亮停留在上一节。** 页面 scroll-padding 与标题 scroll-margin 原先叠加，两次预留导航偏移；现在仅保留标题的 scroll-margin。点击、刷新与当前位置追踪一致，继续使用原生 hash 历史。

文章源码保持原样。README 已补充公式写法、渲染边界和目录行为。

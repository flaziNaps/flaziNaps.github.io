# 文章页与目录整体打磨 — 2026-11-11

本轮在既有浅色、水彩蓝、Poppins/Lora 字体和静态公式方案上改进阅读体验，不改写文章正文或首页。

## 目录：从完整标题堆叠改为阅读导航

- 桌面目录按 H2 分组，将 H3 放入对应章节的小节列表；所有锚点及顺序保持与实际正文一致。
- 脚本初始化后，默认展示主章节和当前章节的小节。顶部的「展开全部 / 收起小节」真实按钮可切换完整目录，提供 `aria-controls` 和 `aria-expanded`。
- 非当前小节只在增强成功后折叠；禁用 JavaScript 或缺少 IntersectionObserver 时全部链接保持可见，不留下不可操作的控制按钮。
- 键盘焦点所在的章节不会随滚动自动折叠。当前章节改变时继续仅滚动目录内部，不修改正文位置、URL 或焦点。
- 主章节文字由较重的深色改为更安静的 14px / 400，当前章节使用既有蓝色和 1px 标记；小节维持 13px、缩进及可读对比度，不用大块底色。
- 保留 240px 侧栏、120px 正文间距和视口内独立滚动；窄桌面仍用 200px，低于 1100px 使用原生折叠目录。链接目标维持至少 44px。

## 文章页

- 标题区增加细分隔线，明确标题、摘要、日期与正文的边界。
- 标题使用平衡换行、1.25 行高与 16px 下间距，摘要调为 20px，让层级更明确。
- 正文行距调为 1.85，首个内容块不再叠加额外上边距；后续 H2/H3、代码、表格、Callout 与公式沿用现有功能。
- 正文保留 700px 宽度，作者内容、标题层级、原文中的连续标题与空章节均未改写。

## 验证

- `npm run build` 通过：Astro 零错误、零警告、零提示。
- `npm test`：9 项全部通过，包含公式、代码、Alerts、日期/草稿、链接协议与分享图。
- `node scripts/reading-fix-check.mjs` 已针对分组目录更新：1100 / 1120 / 1140 / 1280 / 1440 / 1920px × 600 / 900px 验证宽度、边界、目录内部滚动与无页面横向溢出。
- 将实际 H2/H3 ID 与桌面目录链接逐一比较，确认分组不丢失标题或改变锚点顺序。
- 验证键盘展开/收起、按钮状态、正文位置不变、当前小节自动显露、保留焦点所在章节、手动浏览不被重置、hash 点击及刷新。
- 验证无 JS 时所有小节可见、控制按钮隐藏；1024px 桌面和 200% CSS 缩放下折叠目录仍可操作。
- 短文没有小节时不显示多余展开按钮，使用一致的文章标题区。真实笔记中的 7 个公式继续正常显示；无 KaTeX 错误、失败资源请求或未捕获浏览器异常。

实际浏览器版本、测量与检查项在 `checks.json`。

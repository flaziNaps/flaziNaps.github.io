# 目录视觉调整 — 2026-11-11

本轮只调整目录样式和对应阅读区宽度，不更改文章内容、公式渲染、首页或目录追踪逻辑。

- 常规桌面目录由 200px 加宽到 240px。1100–1139px 的较窄桌面窗口仍使用 200px，以保留 700px 正文和 120px 间距；不足 1100px 继续使用原生折叠目录。
- 一级条目为 14px / 500，二级条目为 13px / 400，次级文字颜色与额外缩进区分层级。
- 上下内边距由 12px 收至 8px，减少多行标题占用；链接最小高度仍为 44px，不牺牲点击和键盘操作范围。
- 当前章节取消整块底色，使用蓝字和 1px 细线；hover 仅改变文字颜色。高亮不改变字重，避免状态切换导致换行变化。
- 目录标签缩短与列表之间的间距并对齐文字；标题固定、条目独立滚动、当前项自动跟随和原生 hash 行为沿用此前修复。
